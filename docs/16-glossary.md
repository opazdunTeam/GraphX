# Словарь

| Термин                          | Значение                                                                                                                                                      |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Investigation                   | Отдельное исследование человека или организации                                                                                                               |
| Source                          | Внешний источник данных                                                                                                                                       |
| Source job                      | Бизнес-задание на обращение к источнику                                                                                                                       |
| Artifact                        | Неизменяемый исходный ответ, документ или файл                                                                                                                |
| Processing run                  | Версионированный запуск parser и mapper над artifact                                                                                                          |
| Source record                   | Самостоятельная запись источника, которую можно сопоставить с сущностью                                                                                       |
| Claim                           | Атомарное проверяемое утверждение из источника                                                                                                                |
| Evidence locator                | Указатель на место в artifact, подтверждающее claim                                                                                                           |
| Provenance                      | Цепочка происхождения данных от вывода до оригинала                                                                                                           |
| Entity                          | Канонический человек, организация или другой объект                                                                                                           |
| Entity resolution               | Решение, относятся ли записи разных источников к одной entity                                                                                                 |
| Candidate generation            | Быстрый поиск возможных совпадений                                                                                                                            |
| Match review                    | Задача пользователю на проверку неоднозначного совпадения                                                                                                     |
| Relationship                    | Подтверждённая фактическая связь между entities                                                                                                               |
| Derived relation                | Вычисленная и объяснимая связь; не считается фактом источника                                                                                                 |
| Hypothesis                      | Аналитическое предположение, явно отделённое от фактов                                                                                                        |
| Valid time                      | Время, когда факт был верен в реальном мире                                                                                                                   |
| Publication time                | Время публикации материала источником                                                                                                                         |
| Retrieval time                  | Время получения материала GraphX                                                                                                                              |
| Snapshot                        | Состояние источника на конкретную дату без доказательства непрерывности                                                                                       |
| System time                     | Время появления или изменения записи в GraphX                                                                                                                 |
| Outbox                          | Таблица надёжной публикации сообщения после транзакции БД                                                                                                     |
| Inbox                           | Защита consumer от повторной обработки сообщения                                                                                                              |
| ACK (Acknowledgement)           | Подтверждение RabbitMQ, что сообщение успешно обработано и его можно удалить из очереди. Consumer отправляет ACK только после успешного сохранения результата |
| NACK (Negative Acknowledgement) | Сообщение RabbitMQ о том, что обработка не завершилась успешно. Сообщение можно вернуть для повторной доставки или направить в DLQ                            |
| DLQ                             | Очередь сообщений, которые не удалось обработать штатно                                                                                                       |
| Fixture                         | Зафиксированный тестовый ответ источника                                                                                                                      |
| Parser                          | Код, разбирающий формат источника                                                                                                                             |
| Mapper                          | Код, превращающий разобранные данные в records и claims                                                                                                       |

В коде и контрактах английские имена допустимы и часто точнее. В пользовательской документации рядом используется понятный русский смысл; не нужно изобретать разные переводы одного термина в каждом файле.
