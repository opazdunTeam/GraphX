# ADR-0005. Единый пакет Python-воркеров

- **Статус:** accepted
- **Дата:** 2026-09-19
- **Владельцы:** tech-lead, data

## Контекст

Источники используют JSON, CSV, HTML, PDF и браузерные сценарии. Python имеет подходящую экосистему и известен двум членам команды. Создание отдельного сервиса на источник приведёт к дублированию runtime-кода.

## Решение

Создать один Python-пакет с общим SDK и изолированными адаптерами. Один Docker image запускается как source/document/browser consumer. FastAPI не является обязательным runtime; добавляется только для обоснованного внутреннего HTTP API.

## Рассмотренные варианты

- Go для всех адаптеров;
- отдельный Python-сервис на каждый источник;
- FastAPI вокруг каждого parser.

## Последствия

- единые повторы, логирование, артефакты и contracts;
- source-specific код должен оставаться изолированным;
- процессы можно масштабировать по типу очереди;
- особо тяжёлый Bulk importer может быть реализован на Go после измерений.

## Условия пересмотра

Узкое место производительности, особые зависимости/изоляция конкретного источника или необходимость независимого релиза.
