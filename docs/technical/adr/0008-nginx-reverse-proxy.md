# ADR-0008. Nginx как reverse proxy

- **Статус:** accepted
- **Дата:** 2026-09-19
- **Владельцы:** tech-lead

## Контекст

Demo разворачивается на VPS, где уже используется Nginx. Нужны TLS, временная защита без прикладной регистрации, маршрутизация Vue/API и переключение blue-green upstream.

## Решение

Использовать существующий Nginx как reverse proxy. Конфигурацию проекта хранить в `deploy/proxy/`, а секретные значения и сертификаты — вне репозитория.

## Рассмотренные варианты

- Caddy;
- Traefik;
- публикация контейнеров напрямую.

## Последствия

- не добавляется второй proxy на VPS;
- blue-green требует управляемого обновления upstream и reload после проверки конфигурации;
- внутренние сервисы не публикуют порты наружу;
- конфигурация Nginx становится частью процедуры релиза.

## Условия пересмотра

Переход на другую платформу оркестрации или невозможность безопасно управлять существующим Nginx.
