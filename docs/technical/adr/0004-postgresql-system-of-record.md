# ADR-0004. PostgreSQL как источник истины

- **Статус:** accepted
- **Дата:** 2026-09-19
- **Владельцы:** tech-lead, backend

## Контекст

MVP требует транзакций, происхождения, конфликтующих утверждений, временных данных, нечёткого поиска и выдачи компактного графа. Отдельная графовая БД увеличит сложность согласованности.

## Решение

Хранить канонические и промежуточные структурированные данные в PostgreSQL. Использовать `pg_trgm` для поиска кандидатов. Граф формировать как read-модель. Возможная Neo4j-проекция не является источником истины.

## Рассмотренные варианты

- PostgreSQL + Neo4j с первого релиза;
- MongoDB;
- только графовая БД.

## Последствия

- единая транзакционная модель;
- схема требует миграций и явных индексов;
- сложные многопереходные запросы могут позднее потребовать проекцию;
- JSONB применяется избирательно, а не вместо модели.

## Условия пересмотра

Измеренная неспособность PostgreSQL обслуживать ключевые графовые запросы или подтверждённая потребность в самостоятельном графовом продукте.
