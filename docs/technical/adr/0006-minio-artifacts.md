# ADR-0006. MinIO для исходных материалов

- **Статус:** accepted
- **Дата:** 2026-09-19
- **Владельцы:** tech-lead, data

## Контекст

Система должна сохранять оригинальные HTML, JSON, CSV, PDF и производные тексты. Хранение крупных бинарных данных в PostgreSQL усложнит резервное копирование и повторную обработку.

## Решение

Использовать MinIO с S3 API. Объекты неизменяемы и адресуются системным ключом; PostgreSQL хранит metadata, SHA-256 и происхождение.

## Рассмотренные варианты

- локальная файловая система;
- BLOB в PostgreSQL;
- облачный S3 без локального совместимого окружения.

## Последствия

- появляется отдельный storage service;
- упрощается переход на другой S3-compatible backend;
- требуется согласованное удаление metadata и объектов;
- доступ к bucket не публикуется, файлы выдаются через контролируемый API.

## Условия пересмотра

Переход на управляемое объектное хранилище или доказанная достаточность другого backend при сохранении S3-порта.
